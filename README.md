## Installer

1. Installer l’APK en mise à jour de l’application existante, sans la désinstaller.
2. Au premier lancement, choisir « Télécharger les ressources » puis attendre la vérification et l’installation des deux packs (13,90 Mo décimaux).
3. Les sessions suivantes utilisent les ressources installées hors ligne.

L’import local reste disponible : sélectionner le ZIP dans le lanceur, sans le décompresser. Pour l’APK code 7, utiliser le ZIP de cette release. Une installation complète des packs 1.4.1 réalisée avec l’APK code 6 reste compatible.

## Version

APK **1.4.1-paysages**, code **7** ; contenu **1.4.1** ; Godot **4.6.3 Compatibility** ; Android **10+**, **ARMv7 et ARM64**. Le pack commun 1.4.0 est inchangé ; le monde est dans le pack 1.4.1. Le manifeste précise tailles, empreintes et dépendances.

## État de validation

Préversion de développement. Les six fichiers publiés ont été téléchargés sans authentification et comparés aux originaux : tailles et SHA256 identiques. Signature et alignement de l’APK vérifiés. Son contenu exporté démarre hors réseau sous Godot/Linux ; mise à jour depuis les packs 1.4.0, conservation des paramètres et retour arrière contrôlés dans cet environnement.

Les tests sur téléphone, les performances Android et la reproduction du blocage historique près du parc restent à réaliser. La finition artistique, notamment la vue inverse de Chaillot, reste en cours.

Les archives « Source code » automatiques de GitHub contiennent les fichiers de ce dépôt de distribution. Elles ne constituent pas les sources complètes du jeu, livrées séparément à son auteur.
